# Acquired

A personal museum for accessioning meaningful objects with photographs, provenance, catalog records, and the story of why each thing matters.

**Live app:** https://iphiginea.github.io/acquired/

## About

Acquired treats everyday objects like museum holdings. Instead of letting an object become another unlabeled photograph, it gives each item a permanent accession number and a structured record for what it is, where it came from, how it was acquired, and why it matters.

The interface is intentionally closer to a museum catalog than a social feed, using archival structure and collection language to preserve personal history.

## Features

- Collection-specific accession numbers
- Structured catalog records for title, date, maker, classification, materials, place, acquisition history, provenance, and personal significance
- Photograph upload and collection-grid cropping
- Background removal for object images
- Searchable collection view
- Individual public/private controls for objects
- Account-based personal collections

## Stack

- Supabase for authentication, object records, and image storage
- Browser-based frontend
- GitHub Pages for the public app
